This method adapts already-grounded creative intent to Meta placements. It does not replace buyer research or Ads Strategy and does not claim private knowledge of Meta ranking systems.

---

# 1. Trigger

Use when:

```text
Meta placement materially affects execution
OR
Meta-specific creative diversity / placement behavior is part of the request
```

Current platform facts and policy constraints must be revalidated when they matter.

---

# 2. Inputs

```text
commercial / organic objective
concept family
buyer / audience basis
placement(s)
format / duration
creative assets
copy / CTA
current platform constraints
```

---

# 3. Concept Portfolio Diversity

When producing a portfolio, seek genuinely different communication mechanisms rather than superficial wrappers.

Possible diversity dimensions:

```text
buyer motivation
objection
proof mechanism
presenter / actor role
opening visual
execution style
offer emphasis
format
```

Do not count translations, crops or minor hook changes as independent concepts.

---

# 4. Placement Execution

For each placement, review:

```text
aspect
safe areas
first-frame readability
caption / overlay relationship
muted comprehension when relevant
product / face priority
CTA treatment
platform UI overlap
```

A master concept can produce placement-specific variants without becoming a new concept.

---

# 5. Opening and Progression

The first moment should communicate enough to justify attention.

Check:

```text
opening is specific
visual support begins early
proof / mechanism appears before viewer patience is exhausted
movement adds information
payoff is visible
```

Do not use generic motion merely to create activity.

---

# 6. Muted / Audio-On Modes

Where placement behavior makes both relevant:

```text
MUTED
→ core premise / product / CTA remain understandable enough

AUDIO ON
→ speech / music / SFX add value without masking clarity
```

This is not a rule that every video must be fully self-contained without sound.

---

# 7. Testing Discipline

A platform test should specify:

```text
concept or variable being tested
primary metric
secondary diagnostics
comparable conditions
what result would support / reject the hypothesis
```

Creative variation should be linked to exact concept/variant IDs.

Do not infer performance from public ad recurrence alone.

---

# 8. Localization

For each market, recheck:

```text
buyer context
language
currency / units
offer eligibility
line breaks
voice timing
cultural meaning
claims
CTA / destination
```

Translated copy is not automatically localized creative.
