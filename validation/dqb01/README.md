# DQB-01 research adapter

This directory holds bounded experimental inputs and evidence, not a new runtime
or validation harness. Canonical skill, Web Experience contracts and installed
plugin remain untouched. No dependency on the unmerged PR #7/#9/#10 code.

See [protocol](../../docs/research/dqb01/protocolo.md),
[brief](../../docs/research/dqb01/briefing.md) and
[native competitor preflight](../../docs/research/dqb01/higgsfield-preflight.md).

Inputs are frozen in Git before website implementations. `shared/assets` photographs
are governed by Pexels License, not the repository code license; see credits.json.
Local prototype code and evidence, when produced, belong under `runs/` and `results/`.
Reviewer packets use neutral identifiers; the coordinator mapping is kept separately.
No automated response is accepted as a genuine human review.
