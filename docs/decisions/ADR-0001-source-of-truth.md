# ADR-0001 · Source, media and distribution

**Status:** Owner-approved direction; migration verified separately.

- Public GitHub: versioned source, methods, schemas, executable code, architecture, tests, research and release process.
- Google Drive or other optional asset store: large media and private project materials; not a mandatory runtime dependency.
- Installed skill: self-contained Agent Skill or portable plugin generated from source and independently usable.
- Only one canonical editable source tree. The two ZIP formats must be built, not edited separately.
- Releases, paid calls, publication, character canon changes and permissions remain gated by the user's authorization.
- Use logical asset IDs and separate per-project resolution; no secrets or commercial project media in Git.
