Para a proposta corrente, consultar [STATUS.md](../STATUS.md), [architecture-v0.3.md](../architecture-v0.3.md) e [acceptance-v0.3.md](../acceptance-v0.3.md).

Um antigo checklist de candidatura pessoal ao YouTube foi excluído do snapshot candidato para evitar republicação em uma futura integração. Isso não reescreveu o histórico já público. Documentação de candidatura individual, credenciais, IDs de projeto, referências a clientes e direitos específicos pertencem a armazenamento privado.

**Observação:** links relativos herdados em documentos históricos podem apontar para caminhos antigos. Eles são preservados para auditoria de evolução, e não para execução automática. A aprovação de fonte, licença e retenção exige evidência corrente da autoridade responsável.
