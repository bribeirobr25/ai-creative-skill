# Media Reframe research

Purpose: study image and video reframing tools before implementing new execution routes. Compare crop, tracking, image canvas extension, video canvas extension and layout-based adaptation. Check access methods, resolution, temporal quality, license, cost, and fidelity to original creative assets.

Architecture must reuse existing routing, governance, provenance and QA. Each operation can execute and finish independently. This is a research document, not an approved implementation or installation change.
