## Not recommended

- A second validation engine, quality router or new profiles for every article heading.
- Mandatory moodboards, light comparisons, eight-frame storyboards or casting for all requests.
- Longer prompts as the primary solution: prior project prompts already have concrete direction.
- Universal full-bleed hero styling, 160px image minimum, high-contrast lime palette, fake 3D manufacturing, or obligatory motion.
- Automatic paid retries or copying source-owned skills into distribution.

## Narrow candidate wording for review

For a website whose visual presentation matters, translate the intended visual distinction into the existing direction record. Inspect the rendered primary image, text/action hierarchy and a critical interaction at the requested desktop/mobile sizes. A loaded asset or working control does not establish visual usefulness. When inspection reveals a mismatch, repair the smallest affected surface, preserve protected content/assets, and recheck affected rendering and behavior. Record unresolved preference as awaiting owner review.

This wording belongs in the existing Web method if accepted; it should not expand every request's required document set. The accompanying evidence adapter is optional development tooling, outside the distributed skill.
