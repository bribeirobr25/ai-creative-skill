# R1 · Media Reframe — comparative evaluation (2026-10-20)

**Scope:** evidence-based research and offline synthetic proof of deterministic reframing, **not** V2.6 or production authorization. Source V2.5 `src/ai-creative-skill/` is unchanged. Branch: `feature/media-reframe-research`; PR #2 remains DRAFT.

**Evidence labels:** `DOCUMENTED` = primary vendor/library documentation checked; `AVAILABLE` = interface or local library found; `EXECUTABLE` = accessible in the tested environment; `TESTED` = actually run with specified media and QA; `UNKNOWN` = not established. These are not a strict linear ranking and refer to the **exact operation** (not every feature of a provider). `BLOCKED` denotes an absent prerequisite/approval. Pricing and feature claims may change; verify immediately before any spending.

## 1. Capability taxonomy and comparison matrix

A resize changes dimensions without solving composition; crop removes pixels; pad/blur-backdrop retains all original image pixels (possibly reduced); smart reframe repositions a window subject to scene content; image outpainting synthesizes **new spatial pixels**; video outpainting additionally demands **temporal coherence**. Text/logo pixel fidelity and generated expansion are separate acceptance gates.

## 2. Tested no-cost baseline (real execution, synthetic assets)

Reproducer: [`r1_offline_smoke.py`](./media-reframe/r1_offline_smoke.py). Machine-readable local result: [`r1-local-test-2026-10-20.json`](./media-reframe/r1-local-test-2026-10-20.json).

Environment observed: Pillow **12.3.0**, OpenCV **4.13.0.92** for decoded-frame inspection, FFmpeg **7.1.5** (GPL-enabled binary). **No credentials, GPU, provider call, private media or paid execution.**

- **Image:** 640×360 off-centre synthetic face/product/logo boxes, protected region `(475,85,610,315)`, safely cropped 202×360 from x=438 then scaled to 360×640. **PASS** geometry. When two subjects are at opposite edges (required bounding union x=50..610), 202px crop is unsafe: **detected and switched to full-frame `ImageOps.pad`**, 360×640. Additional pad 500×400 and vertical 360×640 → ultrawide 840×360. **PASS** dimensions and geometry. These are synthetic proxies, not actual face/OCR assessment.
- **Video:** Generated **36** synthetic frames, **3 seconds**, **12 FPS**, one hard scene cut at **1.5s**, moving subject box and synthetic `LOGO`, plus **440Hz AAC** audio. FFmpeg uses manually specified time/scene-dependent crop x, target 360×640. `ffprobe` verified 640×360 → 360×640, 12/1 FPS → 12/1 FPS, **3.0 → 3.0s**, audio present. OpenCV decoded all output frames and found intended subject color in each frame. **PASS** this narrow test. No actual automated visual tracking or real-camera QA was performed.
- **Limitations:** FFmpeg re-encodes video; mapped audio stream copied, but audio **waveform/perceptual integrity beyond presence was not compared**. Synthetic colors and labels do not establish legible logos or identity preservation under real compression. No jitter, smart saliency, real faces, multi-subject motion, neural outpainting, multi-clip temporal coherence or human acceptance certification.

## 3. Selection and capability boundaries

1. **MVP baseline:** deterministic image crop/fit/pad with Pillow, deterministic video crop/pad/overlay and explicit preservation of source audio using FFmpeg; local-only and cost-free (apart from compute). A hard `protected_regions` feasibility gate prevents unsafe crop. If impossible, return `PARTIAL` with pad/backdrop option, or `BLOCKED` when exact fill/crop mandatory. Never silently amputate a face, item or logo.
2. **Optional detection tier:** OpenCV as source of bounding boxes / motion trajectories after scene-change segmentation and smoothing. Not a current capability. Manual boxes and authored trajectories are valid inputs; *do not relabel as automatic smart reframe*. Validate shot discontinuities separately.
3. **Image outpainting:** Diffusers with separately licensed weights for local tests, or fal variants **only with rights/privacy/cost gates and pixel-lock QA**. Model output in generated area is speculative; masks do not guarantee exact content without deterministic compositing of original pixels.
4. **Video outpainting:** defer from portable MVP. Runway GUI and Aleph REST are promising but not interchangeable with FFmpeg crop or a guaranteed source-preserving canvas extension. Multi-cut, logo text, identity, audio, storage policy and route price remain unresolved.
5. **Editorial:** Adobe GUI or blur/backdrop layout as separate output style, not a hidden API dependency. MediaPipe AutoFlip is an unsupported legacy research reference.

**Critical gap:** a verified, zero-cost, portable, high-fidelity **temporally coherent original-preserving video outpainting** stack was **not established** in R1. Frame-by-frame image outpaint does not fulfill this requirement and should not be falsely elevated.

## 4. Proposed MVP interface (research contract, not merged canon)

```json
{
  "operation": "IMAGE_REFRAME | VIDEO_REFRAME",
  "source_asset": {"uri": "local-or-authorized", "sha256": "immutable-source-fingerprint", "rights": "declared"},
  "target": {"width": 1080, "height": 1920, "mode": "CROP | PAD | BACKDROP | GENERATIVE_EXPAND"},
  "composition": {
    "protected_regions": [{"id": "product", "bbox_xyxy": [0, 0, 100, 100], "coordinate_space": "source_pixels", "must_remain_visible": true}],
    "roi_source": "user | manual | detector", "scene_boundaries_seconds": [],
    "max_crop_loss_fraction": 0.0, "allow_source_pixel_replacement": false
  },
  "preserve": {"identity": true, "product": true, "text_logo": true, "audio": true, "fps": true, "duration": true},
  "authority": {"external_upload_authorized": false, "paid_execution_authorized": false, "publication_authorized": false},
  "output": {"destination": "authorized-local", "qa_required": ["geometry", "codec", "timing", "protected_roi", "visual_human"]}
}
```

Contract must be **adapted** to existing V2.5 execution contracts, not installed as a competing schema. Output proposal: `{status: COMPLETE|PARTIAL|BLOCKED|FAILED, source_sha256, selected_execution_route, tool_versions, actual_output_dimensions, media_probe, cost_actual, rights_provenance, qa: {technical, perceptual, human}, output_artifact}`. A `COMPLETE` geometry check does **not** imply human/perceptual acceptance. Entry with approved source and directly bounded request; exit after only requested reframe and QA; optional next action is **never executed automatically**. Reuse `MINIMUM SUFFICIENT TASK PATH`, `HANDOFF_PACKET` and release gates.
