## Contract-model hardening

- Priority/authority and creative latitude are separate axes.
- Creative latitude is task-relative: `PRESERVE | BOUNDED_VARIATION | OPEN_EXPLORATION`.
- `creative_risk_level = SAFE | BALANCED | BOLD | EXPERIMENTAL` applies only to legitimate open/bounded dimensions.
- Distinct-concept tasks have conditional `concept_diversity_acceptance`; controlled variants can be `NOT_APPLICABLE`.
- `creative_latitude_utilization` is diagnostic, not a universal novelty quota.
- User preserve/explore instructions change only named legitimate dimensions.
- Longitudinal identity/continuity anchors to canon/approved authority, not a derivative chain alone.
- Recurrence does not auto-promote an expressive choice into canon.
- `CONSISTENCY != REPETITION`; `CREATIVITY != RANDOMNESS`.
- Concept work can use `EXPLORE → CLUSTER/COMPARE → SELECT → DEVELOP`; bounded edits/repairs bypass it.
- Compliance/fidelity remain eligibility gates before creative ranking.
